Как запустить утилиту?

Выберите **один** из удобных способов запуска:

### 1️⃣ Быстрый запуск через консоль (Самый простой)
Ничего скачивать не нужно. Просто открой **PowerShell от имени Администратора** и вставь эту команду:
```powershell
iex((New-Object Net.WebClient).DownloadString('https://github.com/DenFortos/win_optimizer/releases/latest/download/win_optimizer.ps1'))
```

### 2️⃣ Классический запуск (Скачать архив)
1. Прокрути эту страницу в самый низ до раздела **Assets**.
2. Скачай архив **`win_optimizer_vX.X.zip`** (где X.X — номер текущей версии).
3. Распакуй архив в любую удобную папку.
4. Запусти файл **`win_optimizer.bat`** (он сам безопасно запросит права Администратора).

How to run the utility?

Choose **one** of the convenient launch methods:

### 1️⃣ Quick Launch via Console (The Easiest)
No need to download anything manually. Simply open **PowerShell as Administrator** and paste this command:
```powershell
iex((New-Object Net.WebClient).DownloadString('https://github.com/DenFortos/win_optimizer/releases/latest/download/win_optimizer.ps1'))
```

### 2️⃣ Classic Launch (Download Archive)
1. Scroll down to the bottom of this page to the **Assets** section.
2. Download the **`win_optimizer_vX.X.zip`** archive.
3. Extract the archive to any folder.
4. Run the **`win_optimizer.bat`** file (it will automatically and safely request Administrator privileges).
